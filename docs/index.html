Overview

What is a Mandala Chart?

A Mandala Chart is a 9×9 grid for structured goal planning. Place your main goal in the center, surround it with 8 key themes, then expand each theme into 8 supporting ideas — 64 action items at a glance.

Made famous by baseball star Shohei Ohtani, who used this method in high school to plan his path to becoming a pro player and MLB World Series champion.

Each theme T1–T8 expands into its own 3×3 sub-grid with 8 supporting ideas — 64 action items total.

Installation

Get started in seconds

  1. Open Obsidian → Settings → Community Plugins

  2. Disable Safe Mode if needed

  3. Click Browse and search for Mandala Chart

  4. Click Install, then Enable


▶ Install directly in Obsidian

  1. Download the latest release from GitHub

  2. Extract to .obsidian/plugins/mandala-chart/ in your vault

  3. Enable in Settings → Community Plugins

  1. Install the BRAT plugin

  2. Open BRAT → Add Beta Plugin

  3. Enter:

https://github.com/gurio318/obsidian-mandala-chart

Usage

How to use

📌 Method 1 — Ribbon Icon

Click the grid icon in the left sidebar to open a dedicated full-screen tab. Data auto-saves between sessions.

📝 Method 2 — Embed in Note

Command palette (Ctrl/Cmd+P) → "Insert Mandala Chart", or write the block manually:

```mandala
{
  "center": "My Main Goal",
  "themes": [
    { "theme": "Health", "items": ["","","","","","","",""] },
    { "theme": "Career", "items": ["","","","","","","",""] },
    { "theme": "Skills", "items": ["","","","","","","",""] },
    { "theme": "Finance","items": ["","","","","","","",""] },
    { "theme": "Family", "items": ["","","","","","","",""] },
    { "theme": "Friends","items": ["","","","","","","",""] },
    { "theme": "Hobby",  "items": ["","","","","","","",""] },
    { "theme": "Mind",   "items": ["","","","","","","",""] }
  ]
}
```

✏️ Editing

  • Click any circle → focused theme view
  • Click any cell → edit dialog opens
  • Ctrl/Cmd+Enter to save quickly
  • Theme pills → switch between themes
  • ← Overview → return to 9×9 view

🖨 Printing

  • Click 🖨 Print button (top right)
  • Opens print-optimized page in browser
  • A4 landscape — all 81 cells visible
  • Full colors preserved in output
